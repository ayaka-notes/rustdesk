# Ayaka Theme — Brand & Color Concept

Design tokens for the **ayaka** RustDesk fork. This document is the source of
truth: anywhere the brand color appears (Flutter UI, server-side web admin,
icons, marketing pages) should resolve to the values listed here. To create a
new theme, fork this file, swap the base hex, and regenerate the ramp.

---

## 1. Base palette

| Token   | Hex       | Where it comes from                                  |
|---------|-----------|------------------------------------------------------|
| accent  | `#FF5C8A` | Brand primary. Used for logo gradient start, primary buttons, focus rings, active switches, text selection on dark surfaces, ID-input text on mobile. |
| button  | `#FF85A8` | Lighter accent for hover / pressed states and secondary CTAs. Pre-computed and shipped via `--dart-define=RUSTDESK_BUTTON_ARGB`. |
| ring-2  | `#FFC1D3` | Second gradient stop in the logo SVG (`res/logo.svg`). Pairs with `accent` to form the brand ring. |

Override at compile time:

```
flutter build ... \
  --dart-define=RUSTDESK_ACCENT_ARGB=0xFFFF5C8A \
  --dart-define=RUSTDESK_BUTTON_ARGB=0xFFFF85A8
```

See `flutter/lib/common.dart` (`MyTheme.accent`, `MyTheme.button`).

## 2. Full pink ramp (Ant Design 5 compatible)

For UIs built on Ant Design (e.g. `rustdesk-server-pro`'s web console) the
brand needs a 10-stop ramp so the entire `colorPrimary` token chain — link,
hover, active, background tints — stays coherent. Mirrors antd's algorithm
(tinycolor mix-with-white for 1–5, mix-with-black for 7–10).

| Stop | Hex        | Antd "blue" equivalent | Use                                          |
|------|------------|------------------------|----------------------------------------------|
| 1    | `#FFE6ED`  | `#E6F4FF` (blue-1)     | Page tints, alert backgrounds                |
| 2    | `#FFCEDB`  | `#BAE0FF` (blue-2)     | Light hover backgrounds                      |
| 3    | `#FFAEC5`  | `#91CAFF` (blue-3)     | Disabled-on-light borders                    |
| 4    | `#FF8DAE`  | `#69B1FF` (blue-4)     | Secondary border, hover ring                 |
| 5    | `#FF7099`  | `#4096FF` (blue-5)     | Hover fill on primary surfaces               |
| 6    | `#FF5C8A`  | `#1677FF` (blue-6) ⭐  | **Primary** — same as `accent` above         |
| 7    | `#C93F6C`  | `#0958D9` (blue-7)     | Active / pressed primary                     |
| 8    | `#962D51`  | `#003EB3` (blue-8)     | Strong text on light                         |
| 9    | `#631C35`  | `#002C8C` (blue-9)     | Headings on light                            |
| 10   | `#3D0F1F`  | `#001D66` (blue-10)    | Maximum contrast (rare)                      |

Plus legacy / non-antd blues that rustdesk-server-pro's frontend still ships:

| Upstream blue            | Maps to       | Notes                              |
|--------------------------|---------------|------------------------------------|
| `#1890FF` (antd v4 blue) | `#FF5C8A`     | Older antd; same role as blue-6    |
| `#2EABFF`                | `#FF7099`     | "info" highlight                   |
| `#0071FF`                | `#FF5C8A`     | Upstream logo gradient start       |
| `#00BFE1`                | `#FFADC4`     | Upstream logo gradient end → ring  |
| `#004BA6`                | `#C93F6C`     | Logo dark stop                     |

Status colors (`#52C41A` green / `#FAAD14` warning / `#F5222D` error) are kept
untouched — those are semantic, not brand. Don't repaint warnings.

## 4. Typography & misc

- Mobile remote-ID input: `WorkSans` bold 30pt in `accent` (was hardcoded `#00B6F0`; now aliased via `MyTheme.idColor = accent`).
- Headers: system default; no custom face.
- Logo SVG: `res/logo.svg` is the canonical source. All raster sizes for Android/iOS/macOS/Linux are regenerated by `res/gen_icons.sh`.

## 5. Where the values live

| File                                                         | What it sets                              |
|--------------------------------------------------------------|-------------------------------------------|
| `flutter/lib/common.dart` (`MyTheme`)                        | Flutter accent/button/grayBg/idColor      |
| `res/logo.svg`                                               | Canonical brand SVG (gradient stops)      |
| `res/gen_icons.sh`                                           | Regenerates every PNG/ICNS/ICO from SVG   |
| `.ayaka/patches/hbb_common-option-env.patch`                 | Server name / display name compile-time   |
| `.ayaka/rebrand-server-web/mapping.json`                     | antd-blue → ayaka-pink replacement table  |
| `.ayaka/rebrand-server-web/assets/`                          | Logo + favicon + PWA icons for web admin  |

## 6. Making a new theme (e.g. "ayaka-blue", "ayaka-green")

1. Pick a base hex.
2. Generate the 10-stop ramp:
   - Stops 1–5: mix base with white at 95 / 85 / 70 / 50 / 30 percent.
   - Stops 7–10: mix base with black at 25 / 50 / 70 / 85 percent.
3. Update `flutter/lib/common.dart` `_accentArgb` / `_buttonArgb` defaults (or
   just pass `--dart-define=RUSTDESK_ACCENT_ARGB=0xFF...` at build time).
4. Edit `res/logo.svg` gradient stops; re-run `res/gen_icons.sh`.
5. Copy `.ayaka/rebrand-server-web/mapping.json` → e.g. `mapping-blue.json`,
   adjust the right-hand pink hexes to your new ramp.
6. Replace `.ayaka/rebrand-server-web/assets/{logo.svg,favicon.png,icons/*}`.
7. Run `.ayaka/rebrand-server-web/rebrand.py --mapping mapping-blue.json ...`.

No upstream file is mutated by step 5–7 — only the output directory.
